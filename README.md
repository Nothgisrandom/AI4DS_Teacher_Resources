# AI4DS Teacher Resources: AI Literacy, Statistics & Data Science

A place to organize and share teaching resources that support AI literacy in statistics and data science education.

## Resource folders

| Folder | What to post |
| --- | --- |
| [AI Literacy](01_AI_Literacy/) | Foundational resources about how AI works, its capabilities and limitations, prompt writing, and evaluating AI-generated responses. |
| [Statistics](02_Statistics/) | Teaching resources that connect AI literacy with statistical reasoning, data summaries, uncertainty, sampling, inference, and interpretation. |
| [Data Science](03_Data_Science/) | Resources for data collection, cleaning, visualization, modeling, reproducibility, and evaluating AI-assisted data science workflows. |
| [Lesson Plans](04_Lesson_Plans/) | Complete lesson plans with learning objectives, preparation, teaching steps, timing, and assessment suggestions. |
| [Classroom Activities](05_Classroom_Activities/) | Student-facing exercises, discussion prompts, worksheets, demonstrations, and collaborative projects. |
| [Assessments and Rubrics](06_Assessments_and_Rubrics/) | Quizzes, reflection prompts, performance tasks, answer keys, and rubrics for assessing AI literacy, statistics, and data science learning. |
| [Responsible AI](07_Responsible_AI/) | Resources about bias, privacy, attribution, academic integrity, accessibility, and responsible use of AI in education. |
| [Professional Development](08_Professional_Development/) | Teacher workshop materials, slides, facilitation notes, tutorials, and guides for integrating AI into instruction. |
| [Resource Templates](09_Resource_Templates/) | Reusable templates for documenting and sharing teaching resources. |

## Adding a resource

1. Open the folder that best fits the resource.
2. On GitHub, choose **Add file → Upload files** to upload materials, or **Add file → Create new file** to write a Markdown resource.
3. Use a descriptive filename, such as `Evaluating_AI_Generated_Charts_Activity.pdf`.
4. Include an audience, learning objectives, estimated time, required tools, and attribution. Start with the [resource template](09_Resource_Templates/Resource_Template.md) when useful.
5. Commit the files with a short description of the resource.

Keep student-identifying information and private classroom data out of shared resources. Label the permitted reuse of each resource and obtain permission before sharing third-party materials. No repository-wide reuse license has been selected yet.

The folder README files preserve the structure in Git and explain what belongs in each section. This initial scaffold does not yet contain completed teaching materials.
