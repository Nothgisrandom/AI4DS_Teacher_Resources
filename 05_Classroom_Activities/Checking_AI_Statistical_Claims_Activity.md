# Student activity: checking AI statistical claims

## Scenario and data

These **synthetic** numbers represent the minutes taken to complete a practice exercise in 10 attempts:

```text
10, 12, 12, 14, 14, 15, 16, 18, 20, 45
```

The dataset contains no information about whether AI was used.

## Part 1: calculate before asking AI

1. Calculate the mean and median. Show your work and include units.
2. What does each summary tell you about these attempts?
3. Which observation deserves closer investigation, and why?

## Part 2: audit an example response

The following is an **intentionally flawed example AI response**, provided for this exercise:

> A typical learner finishes in about 18 minutes. The mean is 17.6 minutes and the median is 18 minutes. All completion times are similar, with no unusually long attempt. These results prove that using AI helps learners finish faster.

For each claim, mark it as **supported**, **incorrect**, or **not established by these data**. Explain your decision and give a corrected calculation or identify missing evidence where relevant. Consider how the word “typical” might hide an assumption about the summary or population.

| Claim | Classification | Evidence or correction |
| --- | --- | --- |
| A typical learner finishes in about 18 minutes. | | |
| The mean is 17.6 minutes. | | |
| The median is 18 minutes. | | |
| All times are similar, with no unusually long attempt. | | |
| Using AI helps learners finish faster. | | |

## Part 3: sensitivity and interpretation

1. Temporarily set aside the 45-minute observation and recompute the mean and median.
2. Which summary changes more? Explain what caused the change.
3. Does this justify removing 45 from the dataset? What would you investigate first?
4. Rewrite the example response in three or four sentences using only claims these data support.

## Exit ticket

Name one calculation you would verify in an AI response and one conclusion that would require evidence beyond this dataset.

You can complete the entire activity without an AI account. If your instructor offers an optional AI extension, use only these synthetic data and follow your institution’s tool and privacy policies.
